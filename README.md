## Featured Projects

### [ORBIT](https://github.com/priyanshuprajapati987/ORBIT)

**What:** AI agent system for Minecraft that unifies ideas from open-source projects (Agent Swarm, Voyager, Mindcraft) — event-driven orchestration, multi-agent teams, skill library, memory, vision, and local Ollama support.

**Structure (in repo):** `agents/` `core/` `llm/` `memory/` `vision/` `skills/` `tasks/` `plugins/` `communication/` + `main.py`

**Stack:** Python, asyncio, aiohttp, Ollama (local LLM)

**Status:** In development — see repo for current state

---

### [Game Agent](https://github.com/priyanshuprajapati987/game-agent)

**What:** Generic offline game-automation agent — screen capture, template matching, and state machines, with optional local LLM backends. No API keys required.

**Backends:** OpenCV-only, Ollama, LLaMA.cpp, Transformers

**Stack:** Python, OpenCV

**Status:** Available

**Stack:** Python, Streamlit, Google APIs (genai, youtube upload), edge-tts, ffmpeg

**Status:** Available
